# Tag taxonomy

Controlled vocabulary for tagging raw notes and insight reports. Pick from
this list only — no free-text tags, so reports stay comparable and
searchable over time.

- `onboarding` — account creation, first-run setup, permission prompts
- `checkout` — cart, payment, shipping, order confirmation
- `navigation` — finding features, information architecture, search
- `trust` — anything touching perceived honesty, data use, or credibility
- `pricing` — cost display, discounts, subscription tiers
- `accessibility` — screen reader, contrast, motor/cognitive access
- `support` — help content, contacting support, error recovery

If a note doesn't fit an existing tag, flag it in team standup before
inventing a new one — the taxonomy only stays useful if it stays small.
